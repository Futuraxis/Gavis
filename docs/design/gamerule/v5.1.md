# 规则语言 v5.1 — 零 BUILTIN 与纯数学原语

## 概述

v5.1 移除了 `BUILTIN_FUNCTIONS` 注册表（`check_line`、9 个 `poker_*` 全部退役）。
规则 JSON 完全自足：`functions` 块从声明文档升级为真实 alias 定义
（`{"params": [...], "expr": {...}}`），引擎在构造时经
`expr.set_functions(rules["functions"])` 注册。

## 新增表达式原语（纯数学操作）

| 原语 | 数学操作 | 形状 |
|---|---|---|
| `choose` | 组合 C(n,k) | `{"choose": {"items": L, "k": n, "as": "$c", "prefix": P, "where": P, "then": E, "agg": "max\|min"}}` |
| `range` | 等差数列 | `{"range": {"from": a, "to": b, "step": s}}` |
| `sort` | 排序 | `{"sort": {"list": L, "by": E, "reverse": bool}}` |
| `group` | 分组 | `{"group": {"list": L, "by": E}}` → `[{key, count, items}]` |
| `distinct` | 去重 | `{"distinct": X}` |
| `contains` | 成员 | `{"contains": [container, item]}` |
| `sum` / `max` / `min` | 聚合 | `{"sum": X}` 等 |
| `at` | 动态索引 | `{"at": [container, idx]}`（越界/负索引 → None） |
| `add` / `sub` / `mul` / `div` | 算术节点 | `{"add": [a, b]}` 等（对节点结果做算术） |
| alias `call` | 规则内联函数 | `{"call": ["name", args...]}` — 绑定参数求值函数体 |

关键语义：

- **`choose`**：输入先按值排序去重（C(unique, k)）；`prefix` 前缀剪枝
  （单调契约：部分组合失败 ⇒ 一切扩展失败，文档化）；`where` 判定完整
  组合；`then` + `agg` 返回最优组合值（扑克 `best5` 用）。
- **`at`**：`get` 的第二参数只能是字面量，动态索引必须用 `at`；负索引与
  越界一律返回 `None`（棋盘胜负判定的"自然过滤"契约，防止索引回绕）。
- **`concat`**：全部为列表时摊平拼接；`None` 项在两种模式下都被丢弃
  （部分组合不污染结果）。
- **alias**：禁递归（构造时静态环检测，环上函数调用抛 RecursionError）；
  解释器路径有 32 层深度上限；编译路径内联闭包。`params` 按名绑定
  （`$p` 与 `p` 均可引用）。
- **算术字符串 `expr`**：仅支持标量路径（`$env.x`、常量），`//`、`%`、
  `**` 可用——列表/字典值无法代入，组合型算术用 `add/sub/mul/div` 节点。

## Effector 新增

| op | 语义 |
|---|---|
| `remove` | 多重集差 A⊖B：`{"op": "remove", "array": ..., "value": E, "count": n}` |
| `setArray` | 整体替换数组（env 列表必须整体重绑，禁止原地改——克隆共享陷阱） |
| 表达式 `array` | `append` / `setIndex` / `remove` / `setArray` 的 `array` 支持表达式（如 `{"template": "hand_{$env.turn}"}`） |
| env 列表 | `append` / `remove` / `setArray` 对 env 列表一律重绑新列表，保证克隆隔离 |

## 判定原则

所有判定围绕上下文字段局部计算（O(1) 局部原则，无全局穷举）：

- 五子棋/月亮棋 5/3 连：围绕 `lastPlacedIndex` 的四方向滑动窗口；
  方向以 `constants.dirs`（`{dr, dc}` 表）表达，行列守卫保证不跨行回绕
  （索引步长算术在斜线边缘会错连非共线格，见
  `test_expr_eval.py::TestWinCheckShape::test_anti_diagonal_no_wrap_regression`）。
- 麻将和牌：围绕手牌 + `lastDiscard`/`lastDrawn` 的覆盖验证
  （`Σ min(sel_g, have_g) + wild ≥ 14`，无减法需求）。
- 扑克下注轮结束：`env` 的 committed/acted 字段。
