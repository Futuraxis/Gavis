> **历史文档（已被 v5.2 取代）**：本文档是 v5.0 设计草案，现行规则语言为
> **v5.2**（见 [v5.2.md](v5.2.md)）；v5.1 起零 BUILTIN（`functions` 节
> alias），v5.2 起 `variants`/`visibility` 声明式。本文档仅作版本演进存档；
> 其中 §16「外部函数」描述的是 v5.1 已退役的 `BUILTIN_FUNCTIONS` 设计，
> 请勿按此实现新规则。存量规则 moon_chess.json / stochastic_gomoku.json
> 仍标记 5.0.0（无 variants/无 functions）。

> 版本: 5.0.0 | 状态: 草案（已被 v5.2 取代） | 日期: 2026-07-28
> 前身: [v4.1](v4.1.md) | [游戏模型](../game-model.md)

## 1. 设计目标

v5.0 将 v4.1 从「棋盘特化指令集」升级为 **真正的随机博弈模型描述语言**。核心变化：

1. **双层状态架构**：`groundState`（最小存储）+ `derivedViews`（按需推导），杜绝状态爆炸
2. **实体推导规则**：用坐标运算、枚举、正则推导实体视图，不在 JSON 中枚举
3. **可见性系统**：字段级投影，支持不完全信息游戏
4. **完整概率分布**：explicit / uniform / weighted
5. **效果系统重构**：直接操作 ground state，操作原语补全
6. **JSON 自足**：脱离引擎代码，独立描述完整游戏

## 5. 基础存储 GroundState

### 5.1 GroundFieldDef

```typescript
type GroundFieldDef = ArrayField | EnvField;

interface ArrayField {
  type: "array";
  /** 数组长度（表达式，初始化时求值） */
  length?: Expr;
  /** 是否可变长度 */
  mutable?: boolean;
  /** 元素类型 */
  element: TypeRef;
}

interface EnvField {
  type: "env";
  /** 子字段 */
  fields: Record<string, ScalarFieldDef>;
}

interface ScalarFieldDef {
  type: TypeRef;
  /** 非空时初始值 */
  initial?: any;
}
```

### 5.2 TypeRef

```typescript
type TypeRef =
  | "string" | "int" | "float" | "boolean"
  | "string?" | "int?" | "float?" | "boolean?"
  | "player_id" | "player_id?"
  | { type: "record", fields: Record<string, TypeRef> };
```

### 5.3 示例：Moon Chess

```json
{
  "groundState": {
    "board": {
      "type": "array",
      "length": {"expr": "board_size * board_size"},
      "element": "player_id?"
    },
    "pieceOrder": {
      "type": "array",
      "mutable": true,
      "element": {"cell_id": "string", "player_id": "string"}
    },
    "env": {
      "type": "env",
      "fields": {
        "turn": {"type": "player_id", "initial": "p_black"},
        "round": {"type": "int", "initial": 0},
        "phase": {"type": "string", "initial": "playing"},
        "winner": {"type": "player_id?", "initial": null},
        "lastPlacedCell": {"type": "string?", "initial": null},
        "lastActor": {"type": "player_id?", "initial": null}
      }
    }
  }
}
```

## 6. 推导视图 DerivedViews

### 6.1 DerivedViewDef

```typescript
interface DerivedViewDef {
  /** 推导来源 */
  from: DeriveSource;
  /** 字段定义 */
  fields: Record<string, Expr>;
}

type DeriveSource = ArrayGrid | ArrayEnum | LiteralList | RegexExtract;

interface ArrayGrid {
  /** 源 ground array 名称 */
  array: string;
  /** 推导类型 */
  type: "grid";
  /** 列数（用于计算 row = index / cols, col = index % cols） */
  cols: Expr;
  /** 行索引变量名 */
  rowVar?: string;   // default: "row"
  /** 列索引变量名 */
  colVar?: string;   // default: "col"
}

interface ArrayEnum {
  array: string;
  type: "enum";
  /** 元素 ID 模板 */
  idTemplate?: string;  // default: "{array}_{i}"
}

interface LiteralList {
  type: "literal";
  /** 字面量数组 */
  list: any[];
}

interface RegexExtract {
  type: "regex";
  array: string;
  /** 正则匹配，从数组元素提取字段 */
  pattern: string;
  /** 捕获组命名 */
  captures: Record<string, string>;
}
```

### 6.2 字段上下文

在 derived view 字段的表达式求值中，以下上下文可用：

| 变量 | 含义 |
|------|------|
| `$self` | 当前视图元素（包含 `value` 和 `index`） |
| `$self.value` | ground array 的对应元素值 |
| `$self.index` | ground array 的索引 |
| `$row` | grid 推导的行号 |
| `$col` | grid 推导的列号 |
| `$i` | enum 推导的序号 |

### 6.3 示例：Grid 推导

```json
{
  "cell": {
    "from": {"array": "board", "type": "grid", "cols": {"const": 3}},
    "fields": {
      "id": {"template": "cell_{$row}_{$col}"},
      "occupant": {"get": ["$self", "value"]},
      "x": {"var": "$col"},
      "y": {"var": "$row"}
    }
  }
}
```

等价于：
```
for y in 0..2:
  for x in 0..2:
    Cell(id="cell_y_x", occupant=board[y*3+x], x=x, y=y)
```

### 6.4 示例：Literal 推导

```json
{
  "player": {
    "from": {"type": "literal", "list": {"var": "$players"}},
    "fields": {
      "id": {"var": "$self.value"}
    }
  }
}
```

## 7. 表达式 Expr

基于 v4.1 的 Expr 系统，扩展如下：

```typescript
type Expr =
  | ConstExpr       // {"const": value}
  | VarExpr         // {"var": "$env.turn"}
  | GetExpr         // {"get": ["$entity", "fieldName"]}
  | OpExpr          // {"eq": [...], "and": [...], "neq": [...], ...}
  | IfExpr          // {"if": {"cond": ..., "then": ..., "else": ...}}
  | SwitchExpr      // {"switch": [{"case": a, "then": b}, ...], "input": x}
  | CallExpr        // {"call": ["fnName", arg1, arg2]}
  | TemplateExpr    // {"template": "hello {name}"}
  | QueryExpr       // {"query": viewName} 或 {"query": {"view": ..., "filter": ...}}
  | ExprExpr        // {"expr": "y * board_size + x"} 简写算术
```

### 7.1 新增：SwitchExpr

```json
{"switch": [
  {"case": "p_black", "then": "black"},
  {"case": "p_white", "then": "white"}
], "input": {"var": "$env.turn"}}
```

### 7.2 新增：ExprExpr（算术字符串）

```json
{"expr": "y * board_size + x"}
```

仅支持基本算术（`+`, `-`, `*`, `/`, `%`）和变量替换。

## 9. 动作模板 ActionTemplate

```typescript
interface ActionTemplate {
  /** 模板 ID */
  id: string;
  /** 动作类型 */
  type?: string;
  /** 可用阶段 */
  phases: string[];
  /** 行动者表达式（可选，默认来自 env.turn） */
  actor?: Expr;
  /** 参数定义 */
  params?: Record<string, ParamDef>;
  /** 合法性条件 */
  legal?: Expr;
  /** 关联效果 */
  effectRef: string;
  /** 规范 key */
  canonicalKey?: Expr;
}

interface ParamDef {
  /** 来源视图 */
  view?: string;
  /** 候选域：查询引用或字面量列表 */
  domain?: QueryRef | any[];
  /** 过滤条件（在 domain 之上额外过滤） */
  filter?: Expr;
  /** 是否可选 */
  optional?: boolean;
}
```

示例：

```json
{
  "id": "place_piece",
  "phases": ["playing"],
  "params": {
    "cell": {
      "view": "cell",
      "domain": {"ref": "empty_cells"}
    }
  },
  "legal": {"const": true},
  "effectRef": "do_place_and_check",
  "canonicalKey": {"template": "place:{$cell.x},{$cell.y}"}
}
```

## 10. 效果系统 Effectors

### 10.1 EffectorDef

```typescript
interface EffectorDef {
  /** 效果描述 */
  description?: string;
  /** 效果操作序列 */
  ops: EffectOp[];
}
```

### 10.2 EffectOp

```typescript
type EffectOp =
  | SetIndexOp       // array[i] = value
  | AppendOp         // array.push(value)
  | TrimByKeyOp      // 按 key 分组截断
  | SetEnvOp         // env.field = value
  | IncOp            // env.field += by
  | BranchOp         // if/else
  | CallEffectOp     // 调用子效果

interface SetIndexOp {
  op: "setIndex";
  /** ground array 名称 */
  array: string;
  /** 索引表达式 */
  at: Expr;
  /** 新值 */
  value: Expr;
}

interface AppendOp {
  op: "append";
  array: string;
  value: Expr;
}

interface TrimByKeyOp {
  op: "trimByKey";
  array: string;
  max: Expr;
  key: string;
  value: Expr;
  /** 被淘汰时执行的回调操作 */
  onEvict?: EffectOp[];
}

interface SetEnvOp {
  op: "setEnv";
  key: string;
  value: Expr;
}

interface IncOp {
  op: "inc";
  key: string;
  by: Expr;
}

interface BranchOp {
  op: "branch";
  if: Expr;
  then: EffectOp[];
  else?: EffectOp[];
}

interface CallEffectOp {
  op: "callEffect";
  effectRef: string;
  args?: Record<string, Expr>;
}
```

### 10.3 示例

```json
{
  "do_place": {
    "ops": [
      {"op": "setIndex", "array": "board", "at": {"expr": "$cell.y * board_size + $cell.x"}, "value": {"var": "$env.turn"}},
      {"op": "append", "array": "pieceOrder", "value": {"cell_id": {"get": ["$cell", "id"]}, "player_id": {"var": "$env.turn"}}},
      {"op": "setEnv", "key": "lastActor", "value": {"var": "$env.turn"}}
    ]
  }
}
```

## 12. 随机事件 ChanceDef

```typescript
interface ChanceDef {
  id: string;
  /** 可用阶段 */
  phases: string[];
  /** 概率分布 */
  probability: ProbabilityExpr;
  /** 结果 → 效果映射 */
  effectMap: Record<string, string>;
  /** 规范 key */
  canonicalKey?: Expr;
}

type ProbabilityExpr =
  | { explicit: Array<{outcome: any, prob: number}> }
  | { uniform: {over: string} }
  | { weighted: {over: string, weight: Expr} };
```

示例：

```json
{
  "id": "vanish",
  "phases": ["vanish_check"],
  "probability": {
    "explicit": [
      {"outcome": "vanish", "prob": 0.5},
      {"outcome": "keep", "prob": 0.5}
    ]
  },
  "effectMap": {"vanish": "do_vanish", "keep": "do_keep"}
}
```

## 13. 可见性 VisibilityDef

```typescript
interface VisibilityDef {
  /** 默认可见级别 */
  default: VisibilityLevel;
  /** 例外规则 */
  rules?: VisibilityRule[];
}

type VisibilityLevel = "public" | "private" | "hidden" | "masked";

interface VisibilityRule {
  /** 目标视图 */
  view: string;
  /** 字段可见性设置 */
  fields: Record<string, VisibilityLevel>;
  /** 适用条件（$viewer = 当前观察者） */
  filter?: Expr;
}
```

完美信息游戏：

```json
{"visibility": {"default": "public"}}
```

不完全信息游戏示例（隐藏对手手牌）：

```json
{
  "visibility": {
    "default": "public",
    "rules": [
      {
        "view": "hand",
        "fields": {"suit": "private", "rank": "private"},
        "filter": {"neq": [{"get": ["$node", "owner"]}, {"var": "$viewer"}]}
      }
    ]
  }
}
```

## 16. 函数声明 FunctionDecl

```typescript
interface FunctionDecl {
  description?: string;
  /** 参数列表 */
  args?: Array<{name: string, type: string}>;
  /** 是否纯函数 */
  pure?: boolean;
  /** 是否可用于求解器 */
  solverSafe?: boolean;
}
```

v5.0 中，`functions` 仅做声明和元数据标记，实现在内置函数注册表中（如 `check_line`、`debug_print`）——**该设计已在 v5.1 退役**：现行规则的 `functions` 节是纯别名定义（`{"params": [...], "expr": {...}}`，见 [v5.2.md](v5.2.md) §5「零 BUILTIN 与 functions alias」），不再有外部函数注册表。

## 17. 常量 Constants

`constants` 可在表达式中通过 `$constants.xxx` 引用：

```json
{
  "constants": {"board_size": 3, "win_length": 3, "max_pieces": 3}
}
```

在初始状态初始化时：
```json
{"length": {"expr": "$constants.board_size * $constants.board_size"}}
```

## 19. 从 v4.1 迁移指南

| v4.1 字段 | v5.0 对应 | 变更说明 |
|-----------|-----------|---------|
| `constants` | `constants` | 保留 |
| `queries[].expr` + `query` + `filter` 分离 | `queries[].view` + `filter` | filter 移入 query 内部，引用 `$node` |
| `actions[].actorKind` | 删除 | 未使用，由 `actor` 表达式决定 |
| `actions[].params[].type` + `domain.ref` | `params[].view` + `domain.ref` | 简化 |
| `effects` | `effectors` | 操作原语更新（setIndex 代替 set path） |
| `path: "state.nodes.{id}.props.occupant"` | `op: "setIndex", array: "board", at: ...` | 直接操作 ground array |
| `chance[].effectMap` | `chance[].effectMap` | 保留但标准化 |
| `chance[].probability.explicit[]` | `explicit[].outcome` + `.prob` | 字段名简化 |
| `phases[].actions` | `phases[].actions` | 保留，新增 onEnter/onExit/next |
| `visibility` | 新增 | v4.1 有规范但未实现 |
| `functions` | `functions` | 仅做元数据标记 |
| 状态初始化 | `groundState` + `initialState` | 新增 |
| 玩家 | `players` | 新增 |
