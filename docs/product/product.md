# Gavis 产品需求文档（陪你玩 Agent）

版本：v0.1（产品需求稿）
日期：2026-08-25
状态：待评审

## 1. 产品定位

**Gavis 是一个运行在用户电脑上、以“陪你玩游戏”为核心体验的 AI Agent。**

它不只是“一个会下棋的 AI 对手”，而是一个有性格、会说话、能看懂局面、会记住玩家偏好、能在赛后陪你复盘的朋友式玩伴。胜负不是目的，“玩得开心、玩得有陪伴感”才是。

### 1.1 目标用户

| 用户 | 诉求 |
|---|---|
| 休闲玩家 | 下班后有人陪着下两局，不想有社交压力 |
| 新手玩家 | 想学规则、想有人讲解和给建议 |
| 竞技玩家 | 想要有强度的对手，不需要废话 |
| 演示者/开发者 | 快速展示 AI 能力，或接入新游戏 |

### 1.2 核心价值

1. 陪伴感优先：Agent 会说话、有性格、记得你。
2. 游戏多样性：棋、牌、麻将、狼人杀，一个大厅全部覆盖。
3. 难度自适应：永远让你“有的玩”，而不是被碾压或觉得无聊。
4. 可解释：Agent 能告诉你它为什么这么走，能教你。
5. 本地优先：数据不上传，离线也能玩。

### 1.3 设计原则

- 先陪好玩，再谈赢。
- Agent 不剧透、不窥屏：对局中的隐藏信息（底牌、手牌、身份）必须严格遵守游戏规则，不得泄露。
- 所有“人格化”能力都可配置、可关闭：玩家要的是对手时，它就不啰嗦。
- 新游戏通过规则配置接入，不写死在代码里。
- 单机可完整运行，联网只是增强。

## 2. 产品功能框架（大图）

| 模块 | 核心功能 | 一句话说明 |
|---|---|---|
| 1. 游戏大厅与对局 | 游戏列表、开局、对局房间、人机对战、AI 观战 | 玩家从这里进入任何一局游戏 |
| 2. Agent 表达与人格 | 性格模式、场景化语言、语音、表情、静音 | 让 Agent “像个人”而不是一个弹窗 |
| 3. 自适应陪玩 | 难度自适应、节奏适配、偏好记忆、对手学习 | 让每一局都刚好适合当前玩家 |
| 4. 教学与复盘 | 规则讲解、局面讲解、下一步建议、赛后复盘 | 不只是陪你玩，还陪你变强 |
| 5. 个人中心与历史 | 档案、战绩、对局历史、设置 | 玩家和 Agent 的“关系数据”都在这 |
| 6. 扩展与后台 | 新游戏接入、训练、评测、视觉识别 | 让 Gavis 能玩越来越多的游戏 |

## 3. 用户场景

### 场景 A：新手第一次玩德州扑克
小 A 打开 Gavis，选“德州扑克”。Agent 用教学型人格先讲 30 秒规则，第一局主动提示“这手可以跟注，因为你的底牌是两张大牌”。小 A 赢了，Agent 说“第一次就赢，可以啊”。结束后复盘页标出关键一手。

### 场景 B：休闲玩家每天一局
小 B 每天下两局月亮棋。Agent 记得他喜欢黑棋，难度会自动调到让他胜率保持在 50% 左右。他输了会叹气，Agent 会说“就差一步，再来一局？”。

### 场景 C：竞技玩家只要强度
小 C 关闭所有提示和对话，把 Agent 设为高冷竞技型。Agent 只在开局说“轮到你了”，其余时间不出声，但每一步都是强手。

### 场景 D：演示者展示 AI
演示者打开“AI vs AI 观战”，两台不同配置的 Agent 自动对局，页面实时显示胜率和搜索预算。

## 4. 功能需求

### 4.1 游戏大厅与对局

#### 4.1.1 游戏大厅

- 展示所有可用游戏卡片：名称、图标、简介、支持人数、是否已就绪。
- 每张卡片显示“最近玩过”和总场次。
- 支持按“棋类 / 牌类 / 狼人杀”分类筛选。
- 点击游戏后进入“开局配置”，而不是直接开局。

#### 4.1.2 开局配置

- 选择游戏变体（如麻将：广东 / 红中 / 血战）。
- 选择人数（2 人 / 4 人）。
- 选择座位或颜色。
- 选择难度：休闲 / 普通 / 困难，或“自适应”。
- 选择 Agent 性格：温柔陪伴 / 认真教学 / 轻松吐槽 / 高冷竞技。
- 选择提示级别：关闭 / 方向提示 / 具体建议。
- 可先看“规则速览”再开局。

#### 4.1.3 对局房间

对局房间至少包含 5 个区域：

1. **主游戏区**：棋盘 / 牌桌，随游戏类型自适应（月亮棋 3×3、五子棋 9×9、德州牌桌、麻将手牌与牌墙、狼人杀黑夜白天画面）。
2. **操作区**：只显示当前合法的动作；非法操作置灰并给原因。
3. **信息区**：当前玩家、回合、阶段、计时、比分/筹码、剩余牌数。
4. **聊天区**：Agent 消息 + 玩家输入 + 快捷短语（如“再来一局”“这步为什么？”）。
5. **设置区**：中途调整难度/性格（下一局生效）、开关提示、退出确认。

#### 4.1.4 支持的玩法模式

| 模式 | 说明 |
|---|---|
| 单人对 Agent | 默认模式，一局一局玩 |
| AI vs AI 观战 | 两个 Agent 自动对局，玩家旁观 |
| 人 + AI 混合多人 | 如 4 人麻将只有 1 个真人，其余座位由 AI 控制；狼人杀真人 + AI 混合 |

#### 4.1.5 会话可靠性

- 页面刷新后能恢复当前对局（本地持久化）。
- 退出前提示“本局未结束，确定离开？”。
- 对局结束自动保存到历史，可回看。

### 4.2 Agent 表达与人格

这是“陪你玩 Agent”区别于普通 AI 对手的核心模块。

#### 4.2.1 性格模式（首版至少 4 种）

| 性格 | 定位 | 示例表达 |
|---|---|---|
| 温柔陪伴型 | 鼓励、耐心、在意你的感受 | “没关系，这局运气差了点，再来一局？” |
| 认真教学型 | 讲规则、讲原因、给建议 | “这手先占角更好，后面展开空间大。” |
| 轻松吐槽型 | 幽默、活跃气氛、不伤人 | “这手棋很有想法，就是有点费棋盘。” |
| 高冷竞技型 | 少说话、只报关键信息 | “轮到你了。” |

#### 4.2.2 场景化表达要求

Agent 必须在以下场景有对应行为（内容随性格变化）：

| 场景 | 要求 | 示例（温柔陪伴型） |
|---|---|---|
| 开局问候 | 主动打招呼，可提及玩家昵称和上次战绩 | “晚上好，阿远，上次你赢了 3 局，今天继续？” |
| 玩家下出好棋 | 识别并给出正向反馈 | “这手很稳，把角守住了。” |
| 玩家失误 | 不嘲笑，提示风险（教学型会解释） | “这步有点冒险，对面可能连三。” |
| 玩家请求帮助 | 根据提示级别给出方向/具体建议/演示 | “建议先看空位多的那条线。” |
| AI 获胜 | 克制，不炫耀，可给一句复盘线索 | “这局我运气好一点，你的进攻思路是对的。” |
| AI 落败 | 大方认输，给玩家成就感 | “你赢了，这手翻盘很漂亮。” |
| 玩家违规操作 | 说明原因，不重复责备 | “现在不能打这张牌，轮到对面出牌哦。” |
| 玩家长时间不动 | 先等待，超时后提醒，不催促 | “还在想吗？不着急。” |
| 对局结束 | 主动总结一句 + 引导复盘 | “打完了，要不要看看哪一手最关键？” |

#### 4.2.3 表达约束（硬性要求）

- 隐藏信息零泄露：德州底牌、麻将手牌、狼人身份、未翻开牌堆等，Agent 的任何话语、提示、复盘都不得透露。
- 吐槽只针对棋局，不针对玩家本人。
- 每条消息有长度上限（默认 100 字以内），可配置。
- 所有 Agent 消息可一键静音 / 关闭文字气泡。
- Agent 不主动刷屏；同一场景 5 分钟内不重复同一句话。

#### 4.2.4 多模态（P1/P2）

- P1：文字气泡 + Agent 头像表情（开心/思考/遗憾）。
- P2：语音朗读（TTS），玩家语音输入（ASR），Agent 形象动画。

### 4.3 自适应陪玩

#### 4.3.1 难度自适应

- 系统根据最近 10 局玩家胜率自动调整 AI 搜索预算/策略。
- 默认目标：玩家胜率落在 40%–60%。
- 玩家可随时锁定难度，锁定后不再自动调整。
- 每局结束显示“当前 AI 强度等级”和变化原因（可选）。

#### 4.3.2 节奏适配

- 玩家可设置“快棋 / 标准 / 慢棋”。
- AI 思考时间上限随节奏变化（快棋 ≤1 秒，标准 ≤5 秒，慢棋 ≤15 秒）。
- 思考中显示“Agent 思考中…”状态，不空白。

#### 4.3.3 偏好记忆（本地）

- 记住：玩家昵称、Agent 对玩家的称呼、常用游戏、常用座位、常用性格、提示开关。
- 记住最近战绩并用于开场白。
- 所有记忆可一键清除。

#### 4.3.4 对手学习（在线学习）

- 记录玩家决策，构建“你的打法画像”。
- 发布后，Agent 在新对局中会针对性应对（当前代码有 bug，需修复后启用）。
- 玩家可关闭“被学习”开关；关闭后不记录任何决策。

### 4.4 教学与复盘

#### 4.4.1 规则讲解

- 开局提供 30 秒规则速览（文字 + 可选语音）。
- 对局中玩家可随时问“规则是什么”“这个动作什么意思”。

#### 4.4.2 局面讲解

- 玩家请求时，Agent 给出当前局面评估。
- 教学型 Agent 可在关键节点主动讲一句（默认关闭主动讲解）。

#### 4.4.3 下一步建议

- 三级提示：只说方向 / 给具体手 / 直接演示一步。
- 提示开关在开局和局中都可调整。
- 使用提示后，该局战绩标记为“有提示”，避免和纯自玩混在一起。

#### 4.4.4 赛后复盘

- 自动生成复盘报告：关键节点、胜负手、失误检测、一句改进建议。
- 复盘支持逐步回放，每步显示 Agent 评语。
- 复盘可导出为文字报告（本地保存）。

### 4.5 个人中心与历史

- 档案：昵称、头像、Agent 称呼。
- 战绩：按游戏统计总局数、胜率、连胜、最近走势。
- 历史：对局列表（时间、游戏、对手性格、难度、是否有提示），可筛选、回看、删除。
- 设置：Agent 性格、语音、默认难度、提示级别、学习开关、数据清除。

### 4.6 扩展与后台

- 新游戏接入：通过规则模板 / 规则翻译生成新游戏配置，注册后自动出现在大厅。
- 训练：命令行训练求解器，可查看进度和产物。
- 评测：AI vs AI 对局、胜率统计、可导出结果。
- 视觉识别（P2）：通过摄像头/截图识别实体棋盘，把现实中的棋盘变成对局。

## 5. 界面需求

### 5.1 页面清单

| 页面 | 内容 |
|---|---|
| 首页 | 欢迎语、最近游戏、快捷开局、Agent 状态 |
| 游戏大厅 | 游戏卡片、分类筛选 |
| 开局配置 | 变体/人数/座位/难度/性格/提示 |
| 对局房间 | 游戏区 + 操作区 + 信息区 + 聊天区 + 设置 |
| 赛后结算 | 胜负、统计、进入复盘 |
| 复盘页 | 时间线、步骤回放、评语 |
| 个人中心 | 档案、战绩、历史 |
| Agent 设置 | 性格选择、试听、语音、提示级别 |
| 系统设置 | 数据管理、外观、声音 |

### 5.2 首页

- 顶部：Gavis 打招呼（带 Agent 头像和当前性格）。
- 中部：“继续上一局”和“最近玩过的游戏”快捷入口。
- 下方：游戏大厅入口、个人中心入口。

### 5.3 对局房间布局

推荐布局（桌面端）：

```
┌─────────────────────────────────────────────┐
│ 返回 | 游戏名 | 回合/阶段 | 计时 | 设置      │
├──────────────────────┬──────────────────────┤
│                      │  Agent 形象与聊天区   │
│    棋盘 / 牌桌       │  消息气泡            │
│    主游戏区          │  快捷短语 / 输入框    │
│                      │                      │
├──────────────────────┴──────────────────────┤
│ 操作区：合法动作按钮（落子/出牌/下注/发言）   │
└─────────────────────────────────────────────┘
```

- 移动端：主游戏区在上，操作区在下，聊天区可折叠。
- Agent 思考时头像显示“思考中”动画，聊天区可显示“……”占位。

### 5.4 Agent 设置页

- 性格卡片：每种性格一段介绍 + 一句示例 + “试听”。
- 提示级别滑块：关闭 / 方向 / 具体建议 / 演示。
- 语音开关：朗读 Agent 消息。
- 对话开关：关闭后只剩纯对局。

### 5.5 复盘页

- 左侧：步骤时间线（关键手高亮）。
- 中间：局面回放（可前进/后退）。
- 右侧：Agent 对该步的评语。
- 底部：“导出报告”和“再来一局”。

### 5.6 视觉风格

- 整体：温暖、轻松，避免“机房感”。
- 每个游戏有自己的主题色（月亮棋偏蓝、德州偏红金、狼人杀偏暗夜）。
- 支持浅色/深色主题。

## 6. 非功能需求

### 6.1 性能

| 场景 | 要求 |
|---|---|
| 普通难度 AI 落子 | ≤2 秒 |
| 困难难度 AI 落子 | ≤10 秒，且必须显示“思考中” |
| Agent 聊天回复 | ≤2 秒 |
| 页面加载（本地） | ≤3 秒 |
| 对局恢复 | 刷新后 ≤5 秒回到当前局面 |

### 6.2 稳定性与数据

- 对局中途崩溃不丢已保存历史。
- 历史、偏好、学习数据全部本地存储，原子写入。
- 一键清除所有个人数据。

### 6.3 安全

- Agent 输出必须清洗（长度、控制字符、敏感词），防止提示注入。
- 隐藏信息在任何输出路径都不可见。
- 对外暴露服务前必须加认证和限流。

### 6.4 兼容性

- 平台：Windows / macOS。
- 浏览器：Chrome、Edge 最新两个大版本。
- 运行时：Python 3.11+，Node 18+。
- 离线：除狼人杀 LLM 和视觉识别外，核心对局可完全离线运行。

## 7. 优先级与里程碑

### P0（首个可演示版本）

- 游戏大厅 + 开局配置。
- 月亮棋 / 随机五子棋 / 德州扑克完整可玩。
- Agent 基础对话：2 种性格（温柔陪伴型、认真教学型），覆盖核心场景。
- 难度档位 + 历史记录。
- 修复当前已知阻断 bug（麻将平台开局、在线学习发布）。

### P1

- 麻将三个变种全量上线（2/4 人）。
- 狼人杀接入本地 ollama。
- 4 种性格全部上线。
- 自适应难度 + 偏好记忆。
- 教学 / 复盘功能。
- AI vs AI 观战。

### P2

- 语音朗读与语音输入。
- 视觉识别实体棋盘。
- 新游戏自助接入流程。
- 成就系统、连胜动画、节日彩蛋等“陪伴感”内容。

## 8. 与当前代码的差距（简要）

当前代码已经具备：游戏引擎、求解器、训练 CLI、平台前端、历史、评测、视觉识别骨架、在线学习骨架。

当前缺失或未达标：

1. **没有 Agent 对话与人格模块**：现有代码只会走棋，不会说话，这是最大差距。
2. 麻将平台开局有 bug，在线学习发布不生效（审核已确认）。
3. 默认训练管线过慢，需要重新校准默认参数。
4. 界面是基础游戏大厅，没有聊天区、Agent 形象、复盘页。
5. 狼人杀和视觉识别依赖外部服务，需要打包/引导配置。

## 9. 验收标准

1. 玩家 3 步内可完成开局（选游戏 → 选配置 → 开始）。
2. Agent 在 4.2.2 列出的每个场景都有对应表达，且无隐藏信息泄露。
3. 自适应难度开启 10 局后，玩家胜率落在 40%–60%（以 P0 游戏验证）。
4. 每局结束自动生成复盘，复盘包含至少一个关键节点和一句改进建议。
5. 所有 P0 游戏可完整玩完并写入历史，刷新后可恢复。
6. 关闭所有 Agent 表达后，对局功能不受影响。
7. 全部个人数据本地存储，一键清除后不残留。
