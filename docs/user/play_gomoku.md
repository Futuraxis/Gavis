# 随机五子棋 · 人机对弈（使用说明）

人类与 AI 在浏览器里下随机五子棋。AI 使用 **MCTS**（蒙特卡洛树搜索）。
人机对弈入口统一在平台前端（`layer4_interface/frontend/platform`，
端口 **8770**）；原独立应用 `play_gomoku` 已退役。

## 快速开始

```bash
python -m layer4_interface.frontend.platform.server   # 8770（需先 npm run build）
```

启动后浏览器打开 **http://127.0.0.1:8770/**，在游戏大厅选择"随机五子棋"，
设置执子与难度后开始。前端开发模式（热更新）：

```bash
cd platform-frontend && npm run dev                   # 5173（/api 代理到 8770）
```

## 游戏规则（rules/stochastic_gomoku.json）

- **棋盘**：9×9
- **落子**：黑先白后，交替落子
- **随机消失**：每手落子后，该子有 **50% 概率消失**（棋盘上抹去，由引擎
  `chance` 节点表达）
- **获胜**：任意一方五子连成一线（横/竖/斜）
- **平局**：棋盘下满无人五连

## 界面操作

| 操作 | 说明 |
|------|------|
| 执子选择 | 黑棋先手 / 白棋后手 / 随机。选白棋时 AI 先落子 |
| AI 难度 | 简单 / 正常 / 困难（MCTS 预算 300 / 1500 / 4000） |
| 落子 | 点击空格落子，AI 随后回应 |
| 消失提示 | 落子被抹去时棋盘上相应提示 |
| 再来一局 | 终局后点击重新开局 |

## 难度与耗时（9×9 棋盘，参考值）

| 难度 | MCTS 预算 | 每步耗时 |
|------|-----------|----------|
| 简单 | 300 | ~0.5 秒 |
| 正常 | 1500 | ~2.4 秒 |
| 困难 | 4000 | ~6.5 秒 |

## 对局保存与恢复

平台自动把每局写入本地历史（`data/matches/`），页面刷新后可恢复当前对局，
结束后可在「历史」中回看复盘。
