# 月亮棋 · 人机对弈（使用说明）

人类与 AI 在浏览器里下月亮棋。AI 使用 **MCTS**（蒙特卡洛树搜索），通过
`layer3_solvers` 的求解器与 `layer2_engine` 的 `GameEngine` 交互，无需
截图或 VLM——纯交互对弈。人机对弈入口统一在平台前端
（`layer4_interface/frontend/platform`，端口 **8770**）；原独立应用
`play_moon_chess` 已退役，不再存在独立入口。

## 快速开始

```bash
python -m layer4_interface.frontend.platform.server   # 8770（需先 npm run build）
```

启动后浏览器打开 **http://127.0.0.1:8770/**，在游戏大厅选择"月亮棋"，
设置执子与难度后开始。前端开发模式（热更新）：

```bash
cd platform-frontend && npm run dev                   # 5173（/api 代理到 8770）
```

## 游戏规则（月亮棋，rules/moon_chess.json）

- **棋盘**：3×3，共 9 格
- **棋子**：每方最多 **3 子**，落第 4 子时**最老的棋子被驱逐**（FIFO）
- **获胜**：任意一方**三子连成一线**（横/竖/斜）即胜
- **平局**：50 手内无人三连，判平局
- 先手为黑（●），后手为白（○）

## 界面操作

| 操作 | 说明 |
|------|------|
| 执子选择 | 黑棋先手 / 白棋后手 / 随机。选白棋时 AI 先落一子 |
| AI 难度 | 简单 / 正常 / 困难（对应 MCTS 预算 200 / 800 / 2000） |
| 开始对局 | 进入对局，轮到你可落子时格子可点击 |
| 落子 | 点击空格即落子，随后 AI 思考并回应 |
| 再来一局 | 终局后点击，回到设置页重新开局 |

对局中 AI 思考时棋盘会禁用（不可点击）。

## 难度与耗时

3×3 棋盘较小，AI 每步耗时大致为：

| 难度 | MCTS 预算 | 每步耗时（参考） |
|------|-----------|------------------|
| 简单 | 200 | ~0.2 秒 |
| 正常 | 800 | ~0.5 秒 |
| 困难 | 2000 | ~1.3 秒 |

## 对局保存与恢复

平台自动把每局写入本地历史（`data/matches/`），页面刷新后可恢复当前对局，
结束后可在「历史」中回看复盘。
